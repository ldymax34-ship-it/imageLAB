SVG 转 3D
本地处理 · 素材不上传

01SVG 导入

—

导入简单、轮廓闭合的 SVG；文字请先转曲。 含文本 / 图片 / 滤镜 / 渐变描边的文件会被拒绝并说明原因； 未被使用的普通定义（defs / 元数据）不影响导入。 上限 1 MiB、500 条图形；曲线过多会先自动降低细分，仍超出上限才拒绝。

02立体设置

立方体是 three 原生真实模型：宽高固定 4，厚度 2–100% 即 Z 轴占最大边的比例（默认 100% = 4×4×4）， 边缘圆角宽度映射原生 RoundedBoxGeometry 的圆角半径。 SVG 样例 / 上传仍是挤出模型：厚度 2–100%（首次 16%）、边缘圆角 0–10%、倒角深度 0–10%，0 即关闭； 厚度与倒角按最大平面边长的百分比，倒角只圆立体模型的边缘，深度不超过厚度的一半， 达到几何限制时状态栏会写出实际值。

03材质

当前材质使用它自己的预设折射参数；切到「透明玻璃」可调折射率 / 光学厚度 / 色散强度。

强色散示例会一次填好：原生立方体、透明玻璃、折射率 1.50、色散强度 10，并用页面内 canvas 现画一张白底大号黑字 ImageLAB 图作为背景（本地生成、不联网、不使用任何用户素材）。

未使用贴图

材质预设只提供基础光泽；上传图片可作为表面图案贴在模型上。 支持 PNG / JPEG / WebP，文件不超过 10 MiB、单边不超过 4096 像素。 未勾选自定义颜色时贴图按原色显示，勾选后可用颜色给贴图染色。

04环境与背景

灯光强度是总光量增益：同时缩放白色主平行光、棚拍面光源、可见柔光箱与静态环境反射强度 （环境光滑杆是叠加其上的独立倍数），默认 1.20 为标称；0 时主光与环境反射熄灭、背景色 / 图片保留。 主光是白色平行光、不投影，方向角控制主光与棚拍面光源方位，调参数立即改变真实高光。

未使用背景图片

上传背景图片后可移动裁切位置。

三种背景模式：纯色为默认；棚拍空间是页面内实时生成的真实三维背景（中性灰地面、柔光与地面淡反射）； 图片按「居中铺满（cover）」贴在三维视图里，保持原图宽高比、不拉伸，缩放 1×–3× 放大画面， 横向 / 纵向位置在裁切余量内平移，不会拉伸、平铺或露出空白边。 上传图片会自动切到图片模式，移除后回到纯色；切到棚拍空间时已上传的图片会保留。 支持 PNG / JPEG / WebP，文件不超过 10 MiB、单边不超过 4096 像素。 勾选透明背景时预览与导出都不显示任何背景，取消勾选会恢复原选择。

环境反射由本页实时生成，不联网加载贴图。

05视图与导出

拖拽旋转 · 滚轮缩放 · 右键（或双指）平移。导出为 PNG 图片。
