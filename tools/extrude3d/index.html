SVG 转 3D
本地处理 · 素材不上传

01SVG 导入

—

导入简单、轮廓闭合的 SVG；文字请先转曲。 含文本 / 图片 / 滤镜 / 渐变描边的文件会被拒绝并说明原因； 未被使用的普通定义（defs / 元数据）不影响导入。 上限 1 MiB、500 条图形；曲线过多会先自动降低细分，仍超出上限才拒绝。

02立体设置

立方体是 three 原生真实模型：宽高固定 4，厚度 2–100% 即 Z 轴占最大边的比例（默认 100% = 4×4×4）， 边缘圆角宽度映射原生圆角盒的圆角半径。 SVG 样例 / 上传仍是挤出模型：厚度 2–100%（首次 16%）、边缘圆角 0–10%、倒角深度 0–10%，0 即关闭； 厚度与倒角按最大平面边长的百分比，倒角只圆立体模型的边缘，深度不超过厚度的一半， 达到几何限制时状态栏会写出实际值。

03诊断预览

建模预览是中性灰诊断材质，只用来确认轮廓、厚度与倒角；它不是产品材质，也不导出图片。 拖拽旋转 · 滚轮缩放 · 右键（或双指）平移。画布右上角的「重置视角」恢复摄像机位置与观察中心。 材质、灯光、背景与 PNG 导出都在「渲染」页签，几何参数变更会同步到渲染页签。

01材质

透明玻璃按背面世界坐标预通道估算真实厚度，支持折射、菲涅耳、色散与有限全反射；折射需要背景有细节。

02色散光束

色散光束把白光打进当前用户的 SVG 挤出模型，显示内部折射与出射色散；斜入射（默认 30°）才看得到彩边。

02灯光与曝光

灯光是白色主光 + 页面内实时生成的程序化棚拍环境（上亮下暗墙面与两盏柔光箱），不联网加载任何贴图； 环境反射控制金属 / 塑料的反射强度，曝光在合成阶段统一施加。

03背景

未使用背景图片

上传背景图片后可移动裁切位置。

三种背景：纯色（可选黑 / 白快速预设，或自定义颜色）；棚拍渐变（中性墙面 + 柔光，程序化生成）； 图片按「居中铺满（cover）」贴在视图里， 保持原图宽高比、不拉伸，缩放 1×–3× 放大画面，横向 / 纵向位置在裁切余量内平移，不会拉伸、平铺或露出空白边。 上传图片会自动切到图片模式，移除后回到纯色。支持 PNG / JPEG / WebP，文件不超过 10 MiB、单边不超过 4096 像素。

04镜头与导出

画布右上角的「重置视图」恢复摄像机位置、观察中心与模型默认构图。 导出的是渲染页签当前帧：先按导出倍率重渲染整条 WebGPU 管线，再从渲染结果编码 PNG， 不是截图或建模预览。透明背景时 PNG 带 alpha。
