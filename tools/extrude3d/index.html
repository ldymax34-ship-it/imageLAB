01SVG 导入

—

导入简单、轮廓闭合的 SVG；文字请先转曲。 含文本 / 图片 / 滤镜 / 渐变描边的文件会被拒绝并说明原因。 上限 64 KB、500 条图形；曲线过多、超出上限的文件也会被拒绝。

02立体设置

改参数即时重建模型；平滑度越高，倒角与曲线越顺。

03材质

未使用贴图

材质预设只提供基础光泽；上传图片可作为表面图案贴在模型上。 支持 PNG / JPEG / WebP，文件不超过 10 MiB、单边不超过 4096 像素。 未勾选自定义颜色时贴图按原色显示，勾选后可用颜色给贴图染色。

04环境与背景

反射由本页实时生成，不联网加载贴图。

05视图与导出

拖拽旋转 · 滚轮缩放 · 右键（或双指）平移。导出为 PNG 图片。
