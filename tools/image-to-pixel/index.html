像素化与抖动

缩小到指定像素宽度，再用调色板量化；抖动可选 Atkinson / Floyd-Steinberg / 2x2 / 4x4 / Ordered 8x8 Bayer / Clustered 4x4。 全部在浏览器本地计算，图片不会离开这台机器。

像素化与抖动算法：image-to-pixel.js（Tezumie / Image-to-Pixel，MIT，逐字节原样引用）· 界面外壳与调色板数组由 imageLAB 自建 · 无任何远程请求（调色板一律使用本地数组）

默认示例为仓库内置的本地测试图 tests/fixtures/test-photo.png（640×480），仅用于本页预览。 图片用 FileReader / createObjectURL 在内存中读取，不上传。

px（8–512）

库内取值为 0–100（源码 strength / 100 归一化；上游滑块同样是 0–100）。 0 表示只做调色板量化、不扩散也不扰动误差。

本工具只传颜色数组，从不传 Lospec slug / URL，因此库里的远程取色分支不会被触达。

文件名按实际输出像素宽命名，例如 image-to-pixel-160px.png。
